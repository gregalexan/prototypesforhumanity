# ⚖️ Law Checker
This is the github repo for prototypes for humanity project

## Structure
- `app.py` - Entry point
- `ui/` - Frontent with Streamlit
- `ai/` - AI integration
- `data/` - Laws

## Initializing
```bash
pip install -r requirements.txt
streamlit run app.py
```
